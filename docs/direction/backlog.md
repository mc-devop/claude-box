# Backlog

The ordered queue, and the only place with status. It's ordered by
milestones, each an outcome for you with acceptance criteria, and each
becomes an intent when it starts. Finished work is recorded in its
change's folder under `docs/change/`; how things work is in
the [architecture](../system/architecture/README.md). When an item is
done, it leaves with a link to where it's recorded.
