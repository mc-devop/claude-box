# Vision

Drafted by Claude from the README and the first intent, for the owner to
correct.

claude-box lets Claude Code build in your projects without being able to
act as you. It works in the one project you start it in, reads your
other projects, and sees nothing else of yours. Whatever runs with your
rights (merging, pushing, a script on a server) Claude writes down and
you review and run, in one step, with `dev run`.

Over time, the box stays as easy to live with as a local install:
Claude's home is a folder you open like any other, updating Claude Code
is a rebuild, and what's yours in that home (your instructions, hooks,
permission rules) is out of the box's reach. How it's built today:
[architecture](../system/architecture/README.md). What's next: the
[backlog](backlog.md).
