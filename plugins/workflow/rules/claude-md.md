# A project's CLAUDE.md

Where each fact goes is core's levels rule. A project's `CLAUDE.md` has
these sections, in this order: a first paragraph saying what the project
owns; Start of a session; Commands; Rules; Neighbours' interfaces. Its
Rules section holds the project's own rules and its "Differs from the
default" lines.
